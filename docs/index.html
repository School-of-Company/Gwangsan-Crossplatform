Gwangsan Local Currency App · Account & Data Deletion Guide
앱: 시민화폐 광산 (kr.hs.gsm.gwangsan / gwangsan.io.kr)

1. 앱에서 직접 계정을 삭제하는 방법 (권장)

  1. 시민화폐 광산 앱에 로그인합니다.
  2. 하단 프로필(마이페이지) 탭으로 이동합니다.
  3. 화면 우측 상단의 메뉴 버튼을 누른 뒤 회원탈퇴를 선택합니다.
  4. 안내에 따라 탈퇴를 확정하면 계정이 즉시 삭제되며, 이 작업은 되돌릴 수 없습니다.

2. 앱을 사용할 수 없는 경우 (이메일로 삭제 요청)

휴대폰을 분실했거나 앱에 로그인할 수 없는 등의 사유로 앱 내에서 직접 탈퇴가 어려운 경우, 아래 연락처로 계정 삭제를 요청할 수 있습니다.

3. 삭제되는 데이터와 보관되는 데이터

삭제되는 항목 — 계정 삭제(회원탈퇴) 시 아래 개인 정보가 삭제됩니다.

  • 이름(실명), 닉네임, 휴대폰 번호
  • 비밀번호 및 로그인 인증 정보
  • 프로필 정보(동네, 소개, 관심 분야 등)
  • 기기 푸시 토큰 등 앱 이용을 위해 저장된 부가 정보

일정 기간 보관될 수 있는 항목

  • 거래(광산 결제) 기록 — 5년 (전자상거래 등에서의 소비자보호에 관한 법률)
  • 소비자 불만 및 분쟁 처리 기록 — 3년 (동법)
  • 거래 상대방에게 남긴 후기 — 상대방의 기록 보호를 위해 닉네임을 익명 처리한 상태로 유지

4. 수집하는 개인정보 항목 및 전송 보안

수집 항목이름, 닉네임, 휴대폰 번호(SMS 인증), 동네 정보, 거래 게시글/채팅 내용, 기기 푸시 토큰
전송 구간 암호화모든 API 통신은 HTTPS(TLS)로 암호화되며, 인증서 고정(Certificate Pinning)이 적용되어 있습니다.
