# ADR-0004: 테스트 실행 타임존을 Asia/Seoul로 고정

- 상태: 채택

## 배경

서버 REST 응답의 시각은 `2026-08-30T14:00:00`처럼 **오프셋 없는 KST 문자열**입니다. JavaScript `Date`는 오프셋 없는 문자열을
실행 환경의 로컬 시각으로 해석하므로, 같은 테스트가 로컬(KST)에서는 통과하고 CI 러너(UTC)에서는 실패했습니다.
실제로 거래 카드 정렬 테스트가 이 이유로 CI에서만 깨졌습니다.

테스트 안에서 `process.env.TZ`를 바꾸는 방법은 통하지 않았습니다. Jest 워커가 이미 시작되어 `Date`가 초기화된 뒤라 반영되지 않습니다.

## 결정

[`jest.config.js`](../../jest.config.js) 최상단에서 설정 객체를 내보내기 전에 `process.env.TZ = 'Asia/Seoul'`을 지정합니다.
Jest가 워커를 fork하기 전에 실행되므로 모든 테스트 워커가 같은 타임존으로 시작합니다.

## 결과

- 로컬과 CI의 테스트 결과가 같아졌고, 테스트는 실제 사용자 환경(한국)과 같은 조건에서 돌아갑니다.
- 반대로 다른 타임존 기기에서의 동작은 이 설정으로는 검증되지 않습니다. 앱 사용자가 광산구 주민으로 한정되어 있어 허용한 트레이드오프입니다.
- 서버가 오프셋을 포함한 시각을 내려주게 되면 이 설정 없이도 결과가 같아지므로 다시 검토합니다.
